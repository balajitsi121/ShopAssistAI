# Sample Return Policy (DRAFT - pending PM approval)

## 1. Eligibility
Items can be returned if they are unused and in original packaging. Items marked final sale cannot be returned.

## 2. Return window
Items can be returned within 30 days of delivery.

## 3. How to start a return
Contact support with your order number. Returns are not started by this assistant.

## 4. Refund procedure
Refunds are issued to the original payment method after the returned item is received and inspected.
